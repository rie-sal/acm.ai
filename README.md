# ACM AI at Texas State University

Welcome to the official website repository for ACM AI at Texas State University. Our mission is to explore and advance artificial intelligence education and research within our university community.

## 🌟 Features

- Interactive Dark/Light Mode
- Responsive Design
- Section-based Layout:
  - About Us
  - Events
  - Courses
  - Resources
  - Gallery
  - Team

## 🛠️ Tech Stack

- Next.js 14
- React
- TypeScript
- Tailwind CSS
- Lucide Icons

## 🚀 Getting Started

### Prerequisites

- Node.js (LTS version)
- npm (comes with Node.js)

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```

2. Install dependencies:
   ```bash
   npm install --legacy-peer-deps
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser
